    IRelayBackend

    Datastore-agnostic contract used by the Relay. Every operation is implemented as a single atomic Lua script (Redis) or SQL function (PostgreSQL), so the routing logic is shared verbatim by every BullMQ runtime. Implementations only translate arguments and results.

    Errors are thrown as RelayError with one of the shared codes.

    The contract may change in minor releases while the relay is completed.
